# CharStyleCollect

*Instructions in other languages: [English](README.md)*

Скрипт для Adobe InDesign, который собирает все слова с указанным символьным стилем и помещает их в новый текстовый фрейм через заданный разделитель.

---

## Что делает скрипт

При работе над индексами, глоссариями или аудитом стилей бывает нужно выгрузить все слова, отмеченные конкретным символьным стилем — термины, ключевые слова, имена собственные — не просматривая документ вручную постранично.

**CharStyleCollect** обходит все сторисы документа, собирает каждое слово с указанным символьным стилем и помещает результат в новый текстовый фрейм на первой странице.

1. Обходит все сторисы документа посимвольно
2. Собирает слова, к которым применён указанный символьный стиль
3. Опционально удаляет дубликаты — оставляет только уникальные слова
4. Опционально учитывает регистр при дедупликации
5. Объединяет слова через произвольный разделитель (пробел, запятая, перенос строки, табуляция или любая строка)
6. Помещает результат в новый фрейм с автоподгонкой размера на первой странице

---

## Параметры диалога

- **Character style** — выпадающий список всех символьных стилей документа
- **Separator** — любая строка для разделения слов; поддерживает `\n` (новая строка) и `\t` (табуляция)
- **Unique words only** — удалить повторяющиеся слова из результата
- **Case sensitive** — при дедупликации считать `Слово` и `слово` разными записями

## Установка

1. Скачайте `CharStyleCollect.jsx`
2. Поместите в папку Scripts Panel:
   - **Mac:** `~/Library/Application Support/Adobe/InDesign/[версия]/[язык]/Scripts/Scripts Panel/`
   - **Windows:** `%AppData%\Adobe\InDesign\[версия]\[язык]\Scripts\Scripts Panel\`
3. Откройте панель скриптов: **Window → Utilities → Scripts**
4. Двойной клик по `CharStyleCollect` для запуска

---

## Использование

1. Откройте документ с текстом, оформленным символьным стилем
2. Запустите скрипт
3. В диалоге:
   - Выберите **символьный стиль**, слова из которого нужно собрать
   - Введите **разделитель** (по умолчанию: пробел)
   - Настройте параметры дедупликации
4. Нажмите **Run**
5. На первой странице появится новый текстовый фрейм с собранными словами

---

## Технические детали

- Служебные объекты InDesign (переменные, маркеры сносок, якоря) пропускаются автоматически — в обработку попадают только реальные текстовые символы
- Слова определяются как последовательности непробельных символов внутри стилизованного участка; границами слова служат пробел, неразрывный пробел и абзацный возврат
- Результирующий фрейм автоматически подгоняется по содержимому
