# CaptionAssembler

*Instructions in other languages: [English](README.md)*

Скрипт для Adobe InDesign, который автоматически собирает inline-графику и блоки подрисуночных подписей в сгруппированные объекты — готовые к профессиональной вёрстке.

---

## Что делает скрипт

При работе с иллюстрированными изданиями (научные публикации, книги, отчёты) подписи часто размещаются как обычные абзацы прямо после inline-графики. **CaptionAssembler** находит такие пары и выполняет следующее за один клик:

1. Применяет объектный стиль **Figure** к графике
2. Создаёт фрейм подрисуночной подписи напрямую — без зависимости от Generate Static Caption
3. Переносит текст подписи — включая **несколько абзацев с разными стилями** — в фрейм подписи
4. Группирует графику и фрейм подписи
5. Применяет объектный стиль **Figure Group** к группе
6. Вставляет группу обратно **inline** в текст на исходное место
7. Удаляет исходные caption-абзацы из story

Все абзацные стили исходного блока подписи сохраняются полностью.

## До и после

**До** — inline-графика и абзацы подписи в тексте:

![Before](https://i.ibb.co/yF3FR7Dv/before.png)

```
[inline картинка]
Рис. 2. Остатки органов прикрепления вендских мягкотелых...   ← стиль: "caption"
Условные обозначения: (а) — обр. CU25/6–16; (б)...            ← стиль: "caption source"
Fig. 2. Aspidella-type holdfast fossils...                     ← стиль: "caption EN"
Legend: (a) — sample CU25/6–16; (b)...                        ← стиль: "caption source EN"
```

**После** — inline-группа с иллюстрацией и подписью, caption-абзацы удалены:

![After](https://i.ibb.co/Fk42RWHn/after.png)

```
[inline группа: картинка + фрейм подписи со всеми стилями]
```

## Установка

1. Скачайте `CaptionAssembler.jsx`
2. Поместите в папку Scripts Panel:
   - **Mac:** `~/Library/Application Support/Adobe/InDesign/[версия]/[язык]/Scripts/Scripts Panel/`
   - **Windows:** `%AppData%\Adobe\InDesign\[версия]\[язык]\Scripts\Scripts Panel\`
3. Откройте панель скриптов в InDesign: **Window → Utilities → Scripts**
4. Двойной клик по `CaptionAssembler` для запуска

---

## Требования

- В документе должны быть настроены следующие **объектные стили** (названия на ващ вкус задаются в интерфейсе скрипта):
  - `Figure` — применяется к фрейму с графикой
  - `Caption` — применяется к фрейму с текстом подписи
  - `Figure Group` — применяется к группе

---

## Использование

1. Кликните на текстовый фрейм с inline-графикой
2. Запустите скрипт из панели Scripts
3. В диалоге:
   - Выберите **абзацные стили** которые составляют блок подписи (мультиселект через Cmd/Ctrl+клик)
   - Выберите три **объектных стиля** из выпадающих списков
4. Нажмите **Запустить**

Выбранные настройки сохраняются автоматически и восстанавливаются при следующем запуске.

- **Caption frame** — объектный стиль применяется к фрейму с текстом подписи
- **Group** — объектный стиль применяется к итоговой группе

## Как работают caption-блоки

Caption-блок — это последовательность **идущих подряд абзацев** сразу после inline-графики, каждый из которых имеет один из выбранных стилей. Блок заканчивается как только встречается абзац с другим стилем.

**Пример — один стиль подписи:**
```
[inline картинка]
Рис. 1. Описание иллюстрации.   ← "caption" → блок из одного абзаца
Обычный текст продолжается.
```

**Пример — мультистилевой блок подписи:**
```
[inline картинка]
Рис. 2. Основное описание.              ← "caption"
Условные обозначения: (а) — ...         ← "caption source"
Fig. 2. English translation.            ← "caption EN"
Legend: (a) — ...                       ← "caption source EN"
Обычный текст продолжается.
```

Все четыре абзаца обрабатываются как один блок и помещаются в фрейм подписи.

---

## Советы

- Скрипт обрабатывает только **текущую story** — ту в которой находится курсор или выделение
- Все изменения обёрнуты в **один шаг Undo** — Cmd/Ctrl+Z отменяет всё сразу
- Настройки сохраняются в файл `CaptionAssembler_settings.json` рядом со скриптом
