# CharStyle2Hyperlink

*Instructions in other languages: [English](README.md)*

Скрипт для Adobe InDesign, который превращает текст с указанным символьным стилем в кликабельные гиперссылки. URL берётся прямо из содержимого текста.

---

## Что делает скрипт

При подготовке документов к PDF-экспорту — научных изданий, каталогов, отчётов — URL в тексте нередко покрашены символьным стилем, но не являются гиперссылками. Мне понадобилось сделать ссылками только некоторые из них. **CharStyle2Hyperlink** находит весь такой текст и создаёт из него полноценные ссылки за один клик.

1. Ищет текст с выбранным символьным стилем в заданной области
2. Проверяет каждый текстовый фрагмент на валидность URL (`http://`, `https://`, `mailto:`, `tel:`, `www.`)
3. Очищает URL от мягких переносов и невидимых символов, которые InDesign вставляет при переносе длинных строк
4. Переиспользует существующий `HyperlinkURLDestination` если такой URL уже есть в документе
5. Создаёт `HyperlinkTextSource` и связывает его с destination
6. Выводит отчёт: создано, пропущено, ошибки — с номерами страниц

Все изменения обёрнуты в **один шаг Undo**.

---

## Поддерживаемые схемы URL

- `https://` и `http://`
- `mailto:`
- `tel:`
- `www.` (без схемы)

## Установка

1. Скачайте `CharStyle2Hyperlink.jsx`
2. Поместите в папку Scripts Panel:
   - **Mac:** `~/Library/Application Support/Adobe/InDesign/[версия]/[язык]/Scripts/Scripts Panel/`
   - **Windows:** `%AppData%\Adobe\InDesign\[версия]\[язык]\Scripts\Scripts Panel\`
3. Откройте панель скриптов в InDesign: **Window → Utilities → Scripts**
4. Двойной клик по `CharStyle2Hyperlink` для запуска

---

## Использование

1. Откройте документ с URL, покрашенными символьным стилем
2. Запустите скрипт
3. В диалоге:
   - Выберите **символьный стиль** из выпадающего списка
   - Выберите **область обработки** — весь документ, story текущего фрейма или выделенный текст
4. Нажмите **Run**
5. Изучите отчёт

---

## Диалог

- **Character style** — список всех символьных стилей документа
- **Scope:**
  - *Entire document* — все story включая мастер-страницы
  - *Current frame story* — вся story с активным фреймом (все связанные фреймы)
  - *Selected text* — только текущее выделение

---

## Отчёт

После обработки открывается диалог с результатами:

- ✅ **Created** — гиперссылки успешно созданы
- ⚠️ **Skipped** — текст со стилем найден, но содержимое не является валидным URL
- ❌ **Errors** — URL валидный, но создать гиперссылку не удалось (например, текст уже является источником другой ссылки) — с текстом ошибки

Пропущенные и ошибочные элементы отображаются в прокручиваемых полях с номерами страниц:

```
https://doi.org/10.1038/301053a0 --- page 48 (The object you have chosen is already in use by another hyperlink.)
```

## Технические детали

- Скрипт дедуплицирует результаты `findText` — InDesign иногда возвращает один и тот же объект дважды при наложении символьных стилей
- Мягкие переносы (`↵`), вставленные InDesign внутри длинных URL для визуального переноса строки, автоматически удаляются перед созданием ссылки
- Destinations именуются по URL — никаких автоматических названий `URL 1`, `URL 2`
