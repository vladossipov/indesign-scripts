# Скрипты для InDesign

*In English: [English](README.md)*

Коллекция скриптов для Adobe InDesign для редакционной и книжной вёрстки.

---

## Скрипты

### [CaptionAssembler](CaptionAssembler/)

Автоматически собирает inline-графику и блоки подрисуночных подписей в сгруппированные объекты — готовые к профессиональной вёрстке.
